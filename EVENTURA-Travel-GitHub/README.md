# EVENTURA Travel — GitHub Pages

Це готовий статичний сайт, який можна опублікувати через GitHub Pages. Сервер, збірка або npm не потрібні.

## Структура
- `index.html` — головна сторінка (точка входу GitHub Pages)
- `assets/style.css` — стилі
- `assets/script.js` — інтерактивність

## Як опублікувати
1. Створіть на GitHub репозиторій (або відкрийте свій).
2. Завантажте **вміст цієї папки** у корінь репозиторію: `index.html` та папку `assets`.
3. Перейдіть у **Settings → Pages**.
4. У розділі **Build and deployment** виберіть **Deploy from a branch**.
5. Виберіть гілку `main` та папку `/ (root)`, натисніть **Save**.
6. Зачекайте, поки GitHub Pages опублікує сайт; посилання з’явиться в цьому ж розділі.

## Примітка
Форма зараз демонстраційна: заявки зберігаються лише в localStorage браузера, де відкрито сайт. Для реального приймання заявок потрібне підключення зовнішнього сервісу форм або бекенду. Фотографії завантажуються з Unsplash, тому для них потрібен інтернет.
